# Nova (PWA, работает офлайн)

Файлы: `index.html`, `manifest.json`, `sw.js`, иконки `*.png`, `.nojekyll`. Все загружать в корень репозитория.

## Установка на iPhone
1. GitHub: Settings → Pages → Deploy from a branch → `main` / root.
2. Откройте `https://<логин>.github.io/<репозиторий>/` в **Safari**, подождите 10–20 секунд с включённым интернетом (идёт кэширование).
3. «Поделиться» → «На экран Домой». Дальше запускайте только с ярлыка.
4. Включите авиарежим и откройте ярлык: должно работать. После этого репозиторий можно удалить.

## Важно
- Данные ярлыка (PWA) и вкладки Safari на iOS хранятся раздельно. Если вносили данные во вкладке, сначала «Экспорт данных», затем в приложении с ярлыка «Импорт данных».
- Данные дублируются в localStorage и IndexedDB, плюс запрашивается постоянное хранилище.
- Делайте «Экспорт данных» время от времени: файл сохраняется через меню «Поделиться» → «Сохранить в Файлы». Сохраните также копию `index.html`, на случай если iOS очистит кэш.
- Обновление приложения: измените версию `CACHE` в `sw.js` и перезалейте файлы (пока репозиторий существует).
